# NorthPeak Digital – Agency Landing Page

A modern, responsive one-page agency website built for the **Digital Heroes Internship Qualification Task**.

##  Project Overview

NorthPeak Digital is a fictional digital agency that helps businesses grow through web development, branding, SEO, and digital marketing. This project showcases a clean, modern, and responsive landing page designed using HTML, CSS, and JavaScript.

##  Features

- Responsive navigation bar
- Modern hero section with call-to-action
- About section
- Services section (6 service cards)
- Why Choose Us section
- Client testimonials
- Pricing plans
- Contact form with client-side validation
- Responsive design for mobile, tablet, and desktop
- Smooth scrolling and interactive UI
- Clean, semantic HTML5
- Accessible and user-friendly design

##  Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts (Poppins)

##  Responsive Breakpoints

- Mobile: 360px
- Tablet: 768px
- Desktop: 1440px
